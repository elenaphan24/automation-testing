# ROI Tracking

Automation ROI is tracked with this formula:

```text
ROI = Savings / Investment
```

## Investment

| Sprint | Setup hours | Scripts written | Maintenance hours | Notes |
| --- | ---: | ---: | ---: | --- |
|  |  |  |  |  |

## Savings

```text
Savings = (manual_time_per_run - auto_time_per_run) * runs_per_sprint
```

| Sprint | Manual time per run | Automated time per run | Runs per sprint | Savings hours |
| --- | ---: | ---: | ---: | ---: |
|  |  |  |  |  |

## Sprint ROI

| Sprint | Investment hours | Savings hours | ROI | Cumulative ROI |
| --- | ---: | ---: | ---: | ---: |
|  |  |  |  |  |

## Break-Even Projection

```text
break_even_sprint = first sprint where cumulative_savings >= cumulative_investment
```

The first few sprints may show low or negative ROI while framework setup and dual-running costs are paid down.
